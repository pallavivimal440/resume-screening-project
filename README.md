# Resume Screening App

## 📌 Project Description
This project is a Resume Screening Application that helps in analyzing resumes automatically and selecting suitable candidates based on given criteria.

## 🚀 Features
- Upload resume
- Automatic screening
- Filter candidates
- Easy to use interface
